# Scheda didattica — Evoluzione di Java dalla versione 8 alla 27

Informatica · Programmazione Java · Scheda di studio e verifica

Obiettivo didattico: comprendere come si è evoluto Java, riconoscere le principali funzionalità introdotte nelle diverse versioni e scegliere una versione adeguata per lo sviluppo di applicazioni moderne.

## 1. La linea del tempo

Java evolve attraverso nuove funzionalità del linguaggio, miglioramenti delle prestazioni e aggiornamenti della piattaforma. Alcune versioni sono particolarmente importanti perché sono LTS (Long-Term Support), cioè versioni destinate a un supporto prolungato.

## 2. Le versioni principali e le loro novità

## Java 8

2014

La svolta della programmazione funzionale

- Lambda expressions: permettono di scrivere funzioni in forma compatta.
- Stream API: elaborazione dichiarativa di collezioni.
- Interfacce funzionali.
- `Optional`: gestione più esplicita dei valori potenzialmente assenti.
- Nuova API per date e orari: `java.time`.

Da ricordare: lambda e Stream API hanno cambiato il modo di elaborare i dati in Java.

## Java 11

2018 · LTS

Consolidamento e sviluppo applicativo

- HTTP Client standard, con supporto a richieste sincrone e asincrone.
- Inferenza del tipo con `var` nei parametri delle lambda, quando il tipo è deducibile e la sintassi lo consente.
- Avvio dei programmi con un singolo file sorgente.
- Rimozione di moduli Java EE e CORBA dal JDK.

Da ricordare: una versione LTS importante per le applicazioni aziendali.

## Java 17

2021 · LTS

Un Java più moderno e sicuro

- Sealed classes: controllo delle classi che possono estendere un tipo.
- Pattern matching per `instanceof`.
- Incapsulamento più rigoroso degli interni del JDK.
- Miglioramenti al garbage collector e alle prestazioni.

Da ricordare: una base importante per molti progetti enterprise e Spring Boot.

## Java 21

2023 · LTS

Concorrenza e produttività

- Virtual threads: gestione più efficiente di molte operazioni concorrenti.
- Record patterns.
- Pattern matching per `switch`.
- Sequenced Collections.
- String templates in anteprima in questa versione.

Da ricordare: i virtual threads sono particolarmente interessanti per applicazioni con molte operazioni I/O.

## Java 24

2025

Miglioramenti alla concorrenza

- JEP 491: miglioramenti al comportamento dei virtual threads quando utilizzano `synchronized`.
- Riduzione di alcune limitazioni che potevano causare il cosiddetto pinning dei virtual threads.

Da ricordare: Java 24 non è una versione LTS.

## Java 25

2025 · LTS

Una nuova base a supporto prolungato

- Include i miglioramenti della piattaforma introdotti nelle versioni precedenti.
- Prosegue l'evoluzione di concorrenza, sicurezza e prestazioni.
- È una scelta da valutare per nuovi progetti e aggiornamenti di applicazioni.

Da ricordare: è la versione LTS successiva a Java 21 nell'elenco della scheda.

## Java 27

2026

Evoluzione continua della piattaforma

- Nuovi miglioramenti a prestazioni e produttività.
- Prosecuzione dell'evoluzione del linguaggio e delle API.
- Opportunità per sperimentare le novità delle release più recenti.

Da ricordare: è una release a breve ciclo, non una versione LTS.

## 3. Concetti fondamentali da conoscere

| Concetto          | Significato                                                                              |
| ----------------- | ---------------------------------------------------------------------------------------- |
| LTS               | Versione con supporto a lungo termine.                                                   |
| Lambda expression | Sintassi compatta per rappresentare un comportamento.                                    |
| Stream API        | API per elaborare sequenze di dati tramite operazioni come `filter`, `map` e `collect`.  |
| Record            | Tipo pensato per rappresentare dati, con una sintassi concisa.                           |
| Pattern matching  | Tecnica che combina verifica del tipo e accesso al valore.                               |
| Virtual threads   | Thread leggeri gestiti dalla JVM, utili per applicazioni con molte operazioni bloccanti. |
| Garbage collector | Componente della JVM che recupera memoria occupata da oggetti non più utilizzabili.      |

## 4. Esempi di codice

### Esempio A — Lambda e Stream API (Java 8)

```
import java.util.List;

public class EsempioStream {
    public static void main(String[] args) {
        List<Integer> numeri = List.of(2, 5, 8, 11, 14);

        numeri.stream()
              .filter(n -> n % 2 == 0)
              .forEach(System.out::println);
    }
}
```

Domanda: quali numeri vengono stampati?

Suggerimento: `filter` seleziona gli elementi che soddisfano una condizione; `forEach` applica un'azione a ogni elemento selezionato.

### Esempio B — Record e pattern matching (Java 21)

```
record Studente(String nome, int voto) {}

public class EsempioRecord {
    public static void main(String[] args) {
        Object dato = new Studente("Anna", 28);

        if (dato instanceof Studente(String nome, int voto)) {
            System.out.println(nome + ": " + voto);
        }
    }
}
```

Domanda: quale vantaggio offre il pattern matching rispetto a una verifica del tipo seguita da un cast esplicito?

## 6. Attività pratica

Scegli una versione di Java e realizza un piccolo programma per gestire una lista di studenti.

Il programma deve:

1. Creare una lista di almeno cinque studenti.
2. Associare a ogni studente un nome e un voto.
3. Selezionare gli studenti con voto maggiore o uguale a 24 utilizzando la Stream API.
4. Stampare i nomi degli studenti selezionati.
5. Spiegare quali funzionalità del linguaggio sono state utilizzate e da quale versione sono disponibili.

Estensione: se utilizzi Java 21 o superiore, rappresenta lo studente con un `record` e confronta la soluzione con una classe tradizionale.

Rispondi brevemente alle seguenti domande aperte.

- Perché Java 8 è considerata una versione fondamentale?
- Qual è la differenza tra una versione LTS e una release intermedia?
- Perché i virtual threads possono migliorare un backend che effettua molte chiamate HTTP o al database?
- Perché aggiornare Java richiede anche di verificare framework, librerie e dipendenze?
- Per un nuovo progetto Spring Boot, quali elementi valuteresti prima di scegliere Java 21 o Java 25?

Messaggio chiave: conoscere le versioni di Java non significa soltanto ricordare le date. Significa capire quali strumenti offre la piattaforma, quali problemi risolvono e come scegliere una versione coerente con i requisiti, la compatibilità e il ciclo di vita del progetto.
