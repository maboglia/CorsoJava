# 09 — Progetti

I progetti consolidano ogni modulo e costituiscono la verifica finale del percorso.

## Progressione

1. **Applicazione console**: gestione di una lista di oggetti con menu, validazione ed eccezioni.
2. **Applicazione file/database**: importazione dati, persistenza JDBC e report.
3. **REST API**: Spring Boot, DTO, validazione, gestione errori e test.
4. **Applicazione completa**: Spring Boot, JPA, database, interfaccia web, test e pipeline CI.

Ogni progetto dovrebbe includere README, istruzioni di esecuzione, test automatici, gestione della configurazione e una breve descrizione delle decisioni architetturali.
