Comprendere HTTP e il modello request/response, quindi sviluppare applicazioni web moderne con Spring Boot.

5. JSON e REST
6. [JPA/Hibernate con Spring](../../appunti/077_Spring_JPA_Hibernate.md)
7. [Thymeleaf](../../appunti/079_thymeleaf.md)

## Nota di aggiornamento

Servlet e JSP sono mantenuti per comprendere il fondamento storico della piattaforma, ma il percorso principale dovrebbe privilegiare Spring Boot, REST, JSON, validazione, sicurezza e testing.
