# Memory

Realizzare un semplice gioco di Memory da console.

Creare un insieme di coppie di simboli, ad esempio:

`A A B B C C D D E E`

Mescolare casualmente le carte e disporle in una griglia.

A ogni turno il giocatore deve indicare le coordinate di due carte:
- le carte vengono scoperte;
- se sono uguali, rimangono scoperte e il giocatore guadagna una coppia;
- se sono diverse, vengono nuovamente nascoste.

La partita termina quando tutte le coppie sono state trovate.

Il programma deve mostrare:
- la griglia;
- il numero di coppie trovate;
- il numero di tentativi effettuati.

### Obiettivo didattico
Utilizzare array bidimensionali, cicli, condizioni e generazione casuale.
