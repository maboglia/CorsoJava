# Esercitazione 6 — Agenda degli appuntamenti

Realizzare un semplice programma per gestire un'agenda.

Creare una classe `Appuntamento` con:
- descrizione;
- giorno;
- mese;
- anno.

Prevedere costruttori adeguati e i metodi getter/setter necessari. Aggiungere un metodo che restituisca la data in formato `giorno/mese/anno`.

Creare quindi una classe `Agenda` che contenga una collezione di appuntamenti.

L'agenda deve permettere di:
- aggiungere un appuntamento;
- elencare tutti gli appuntamenti presenti.

Nel programma principale:
1. creare un'agenda;
2. inserire alcuni appuntamenti;
3. visualizzarli;
4. aggiungere un ulteriore appuntamento e verificare che venga visualizzato.

Utilizzare una `ArrayList<Appuntamento>` per la gestione dinamica degli appuntamenti.
