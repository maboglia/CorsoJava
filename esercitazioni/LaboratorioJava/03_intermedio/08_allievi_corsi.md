# Esercitazione 8 – Allievi e corsi

Realizzare in Java un'applicazione per la gestione di corsi di formazione e dei relativi allievi.

Definire una classe `Allievo` con:
- nome;
- cognome;
- età;
- indirizzo.

Definire una classe `Corso` con:
- descrizione;
- durata in ore;
- elenco degli allievi iscritti.

L'applicazione deve gestire più corsi, ad esempio Java, SQL e HTML/CSS.

Il programma deve permettere di:
1. scegliere un corso;
2. inserire un nuovo allievo nel corso selezionato;
3. visualizzare le informazioni del corso e l'elenco degli allievi iscritti;
4. terminare il programma.

Il numero massimo di allievi di un corso deve essere definito in fase di creazione del corso. Gestire il caso in cui il corso abbia raggiunto la capienza massima.

Utilizzare classi separate, array o collezioni di oggetti e metodi di accesso agli attributi. Organizzare il programma in modo che la classe principale si occupi dell'interazione con l'utente mentre le classi del dominio gestiscono i propri dati.
