# Esercitazione 7 – Rubrica telefonica

Realizzare in Java un programma per la gestione di una rubrica telefonica.

Ogni voce della rubrica deve contenere almeno:
- nome del contatto;
- numero di telefono.

La rubrica deve utilizzare una struttura dati dinamica, in modo da non avere un numero massimo prefissato di contatti.

Il programma deve permettere all'utente di:
1. aggiungere una voce;
2. eliminare una voce;
3. visualizzare l'elenco completo dei contatti;
4. cercare un contatto per nome;
5. terminare il programma.

Stabilire un criterio per evitare l'inserimento di duplicati e gestire correttamente le operazioni richieste su contatti inesistenti.

Separare le responsabilità tra le classi: una classe deve rappresentare la singola voce della rubrica e un'altra deve gestire l'insieme delle voci.

Realizzare un menu interattivo da console e utilizzare una collezione dinamica, ad esempio `ArrayList`.
